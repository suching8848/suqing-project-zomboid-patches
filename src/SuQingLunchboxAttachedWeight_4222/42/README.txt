蘇清的返鲜餐盒外挂减重修复 0.1.0-rc.1

适用于 B42.22.2 单人和 ZombieBuddy 2.3.4。需要同时启用 SuQingFreshnessLunchbox。
Mod ID 为 SuQingLunchboxAttachedWeight_4222。Java JAR 需要在原生加载器中批准。

背包底部的普通、大型和 ALICE 挂点采用以下重量。
餐盒自重乘以原生外挂系数，再加内容物重量乘以剩余负重比例。
减重随当前餐盒及升级等级变化。例，自重1、食品13.7、减重99时为0.837。
角色负重和原生重量提示使用同一返回值。

把本目录所属模组放入本地 mods，启用前置和补丁，并完整重启游戏。
停用后完整重启即可使用原生外挂重量。已有物品和升级记录继续可用。
当前完成离线验证后交付游戏内复测。

SuQing's Lunchbox Attached Weight Fix 0.1.0-rc.1

For B42.22.2 single-player and ZombieBuddy 2.3.4. Enable SuQingFreshnessLunchbox as well.
Mod ID is SuQingLunchboxAttachedWeight_4222. The native loader requires approval of the Java JAR.

The ordinary, large and ALICE backpack-bottom slots use the native attached multiplier for
the box itself, plus the contents multiplied by the remaining weight percentage.
The current lunchbox upgrade determines the reduction. A box weighing 1 with 13.7 of food
and 99 percent reduction contributes 0.837. Carry weight and native tooltips share this value.

Place the mod in local mods, enable its dependencies and the patch, then fully restart.
Disable the patch and fully restart to resume native attached weight.
Existing items and upgrade records remain usable. In-game acceptance follows offline validation.
